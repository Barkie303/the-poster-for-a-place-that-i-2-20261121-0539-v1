A travel poster for **Tidefall**, an invented cliff town where a river
pours off the cliffs into a turquoise bay at golden hour — white houses
with terracotta roofs, a striped lighthouse, and one sailboat on the
water. The place name is set into the picture in large serif type, with
the line "WHERE THE RIVER MEETS THE SKY" beneath it.

## Run it

```sh
python3 render.py   # redraws entry.png (1024x1024, Pillow)
node main.ts        # copies entry.png to /output/entry.png
```

`render.py` draws the whole poster with Pillow at 2x and downscales it
to 1024x1024; nothing is borrowed, photographed, or fetched over the
network.
